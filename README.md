# BookHive Static UI Foundation

This version is intentionally UI-only.

- No JavaScript logic
- No database
- No authentication
- No CRUD implementation
- No backend

Files:
- `user.html` — main reader/member UI
- `admin.html` — librarian/admin UI
- `style.css` — shared styling

Open either HTML file directly in a browser.

This is a visual foundation for the team. Later, the team can rebuild/connect the interface in Python/Tkinter and add the programming logic required by the course.
